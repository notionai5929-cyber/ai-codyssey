# 프로젝트 개요(미션 목표 요약)
개발자로서 코드를 작성하기 전 필수적으로 갖춰야 할 '로컬 개발 환경'을 구축하는 과정입니다. 
터미널(CLI), Docker, Git/GitHub라는 세 가지 핵심 도구를 직접 세팅하며 다루는 방법을 익히게 됩니다.

- OS : Windows(PowerShell)
- Docker : 29.9.2, build a82e528
- Git :2.56.0.windows.4
